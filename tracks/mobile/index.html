移动端

MOBILE · Android / iOS / 鸿蒙

原生开发直接调用平台能力，性能与体验上限最高。三套平台语言与框架各异，但声明式 UI、生命周期、权限与后台这些原理是相通的。懂原理，就能跨平台迁移判断。

三大平台

PLATFORMS
🤖

Android

规划中

Kotlin + Jetpack Compose。

  • 基础：Kotlin、协程、Activity/Fragment 生命周期
  • 框架：Jetpack Compose / ViewModel / Room
  • 架构：MVVM、模块化、后台与权限
Android 原生、深度系统集成、硬件能力
🍎

iOS

规划中

Swift + SwiftUI。

  • 基础：Swift、并发 async/await、App 生命周期
  • 框架：SwiftUI / Combine / SwiftData
  • 架构：MVVM、审核与隐私规范
iPhone/iPad、苹果生态联动、高品质体验
🌸

鸿蒙

规划中

ArkTS + ArkUI。

  • 基础：ArkTS、状态管理、Ability 生命周期
  • 框架：ArkUI 声明式 / 分布式能力
  • 架构：多设备协同、信创适配
HarmonyOS、多设备协同、国产适配

移动端选型决策

WHEN TO USE WHAT
场景约束倾向关键理由
只做 Android、要深度系统能力Android 原生平台能力最全、性能上限高
只做 iOS、重体验与生态iOS 原生SwiftUI 体验、苹果生态联动
面向鸿蒙 / 信创市场鸿蒙原生分布式能力、国产生态准入
三端都要、团队有限跨平台（见下一方向）一套代码多端，效率优先
原理相通三端的声明式 UI、状态驱动渲染、生命周期与权限模型高度同构。学会一端的核心原理，另两端是「换语法不换思想」——这正是 AI 时代快速跨平台的基础。
