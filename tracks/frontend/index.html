前端

FRONTEND · Vue / React

前端负责浏览器端的界面与交互。Vue 与 React 代表两种思想：渐进式模板 vs 函数式组件。懂它们的响应式原理、组件模型与状态管理，才能按团队与项目复杂度选对框架。

两大框架，两种思想

FRAMEWORKS
💚

Vue

规划中

渐进式、模板直观、上手快。

  • 基础：响应式原理、组合式 API、生命周期
  • 框架：Vue 3 / Vite / Pinia / Vue Router
  • 架构：组件设计、状态管理、SSR（Nuxt）
中后台、快速交付、中小团队、渐进改造
⚛️

React

规划中

函数式 + 组件化，生态最大。

  • 基础：JSX、Hooks、渲染与协调机制
  • 框架：React 18 / Next.js / 状态库
  • 架构：组件组合、服务端组件、跨端复用
复杂交互、大型应用、强生态、RN 复用

前端选型决策

WHEN TO USE WHAT
场景约束倾向关键理由
快速交付、团队偏新手、中后台Vue模板直观、约定多、上手与协作成本低
复杂交互、大型应用、要跨端React灵活组合、生态最大、与 RN 共享技能
内容站、要 SEO 与首屏Next / NuxtSSR/SSG 框架，按所选生态对应
交给 AI 的指令长这样「用 Vue 3 + Vite + Pinia 做一个中后台，按路由懒加载拆模块，列表用虚拟滚动，表单校验抽成组合式函数。」—— 框架与约束你定，AI 实现，你验收交互与性能。
