后端

BACKEND · Java / Python / Go / Node.js

后端负责业务逻辑、数据存储、并发处理与系统集成。AI 时代你不必精通每种语言的每个 API，但要懂它们的并发模型、生态定位与适用边界，才能按场景选对语言、把架构交给 AI 实现。

LANGUAGES

Java

中级样板已写

企业级主力，JVM + Spring 生态。

  • 基础：JVM 内存/线程、GC、并发
  • 框架：Spring Boot / MVC / 虚拟线程
  • 架构：模块化单体 → 微服务、事务、消息队列
大型业务系统、高并发网关、长期维护服务
🐍

Python

规划中

AI 与数据首选，开发效率高。

  • 基础：异步 asyncio、类型提示、包管理
  • 框架：FastAPI / Django / Pydantic
  • 架构：AI 服务、数据管道、任务队列
AI 服务、数据处理、快速原型、自动化
🐹

Go

规划中

云原生标配，简洁高效。

  • 基础：goroutine / channel、接口、错误处理
  • 框架：Gin / Echo / gRPC
  • 架构：微服务、中间件、高并发 API
微服务、云基础设施、高并发网关
🟢

Node.js

规划中

前后端同语言，事件驱动。

  • 基础：事件循环、异步、Stream
  • 框架：Express / NestJS / Fastify
  • 架构：BFF、实时应用、Serverless
全栈 JS 团队、实时应用、BFF 聚合层

后端选型决策

WHEN TO USE WHAT
场景约束倾向关键理由
大型团队、长期维护、强类型Java生态与人才储备、可维护性、JVM 调优空间
AI/数据密集、要快速出活Python模型与数据库最全、开发速度
高并发、低资源、易部署Go轻量并发、单二进制、云原生契合
前后端同栈、IO 密集实时Node.js技能复用、事件驱动、迭代快
交给 AI 的指令长这样「用 Spring Boot 3 + JDK 21 虚拟线程做一个模块化单体的 AI 网关，按认证/限流/路由/计量分模块，配额扣减用事务保证不重扣，异步入账走 RabbitMQ + Outbox。」—— 你定架构与约束，AI 写实现，你验收。
